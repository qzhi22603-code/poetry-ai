# poemly 微调训练数据

## 试产集（pilot）：poemly_sft_pilot.json

- **格式**：Alpaca（`instruction` / `input` / `output`），LLaMA-Factory 直接可用（dataset_info.json 里注册为 alpaca 类型即可）
- **规模**：56 条 = 作诗 34 + 韵部问答 9 + 典故问答 9 + 身份 4
- **生成方式**：
  - 作诗样本：大模型（GLM-5.3）逐首手写，每首经过脚本自动质检
  - 韵部问答：从《平水韵字表》（知识库）程序化生成，**零事实错误**
  - 典故问答：大模型撰写，出处均为经典文献（《庄子》《诗经》《汉书》《列子》等）
  - 身份样本：修正模型自我认知（poemly / 非 ChatGPT）

## 作诗样本的输出模板（即训练目标格式）

```
立意：一两句话点明主题与情感。
<空行>
诗：
《题目》
每句恰好 5 或 7 字，两句一行。
<空行>
意象解释：
"句"——逐句解释意象与立意的关系。（到此为止，无任何总结）
```

## 自动质检规则（build_dataset.py）

1. 每句字数严格等于 5 或 7（按标点切分后逐句验证）
2. 绝句 4 句、律诗 8 句
3. 韵脚（偶数句末字）必须在平水韵同一韵部（对照知识库韵表，简繁转换后比对）
4. 结尾不得出现"以上/总之/希望/如有不足"等客套总结
5. 不得复述五条准则

## 体裁分布（作诗 34 首）

五言绝句 10 ｜ 七言绝句 10 ｜ 五言律诗 8 ｜ 七言律诗 6
题材：四季、山水、送别、思乡、边塞、田园、咏物（梅竹松荷月雁）、登临、读书、喜雨、怀人……

## 扩产计划（用户确认格式后）

- 作诗样本扩至 ~3000：题材×体裁全组合 + 词（词牌按词林正韵）
- 加改诗样本（五言改七言、出律修正）——直接治"分不清五言七言"
- 加自动RAG协同样本（检索结果在上下文中时的作答）
- 每批都过质检脚本，韵律错误零容忍

## 训练用法（LLaMA-Factory）

dataset_info.json 增加：
```json
"poemly_sft": { "file_name": "poemly_sft_pilot.json", "columns": { "prompt": "instruction", "query": "input", "response": "output" } }
```
基座 qwen2.5:3b（GGUF 需转回 HF 格式或直接用官方 qwen2.5-3b-instruct 权重），LoRA rank 8-16，学习率 1e-4~2e-4，3 epoch 起步。
